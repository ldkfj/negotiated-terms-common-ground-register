# Frontend Design Rationale

The interface uses the mathematical intersection mark and paired editorial panels to express the product's narrow purpose: discovering overlap without collapsing two authors into one. Deep green signals durable public records; muted gold highlights the semantic intersection without implying approval, payment, or legal authority.

The primary workspace keeps Party A and Party B visually equal. Neither side is presented as claimant, winner, or administrator. Freeze state is visible beside each offer, and the comparison table preserves one-sided terms instead of hiding them. The public transaction panel remains separate from the negotiation result so network progress cannot be mistaken for common-ground success.

The landing page explains the trust problem before presenting controls. The final How it works section repeats the full actor and verification journey for a first-time visitor and states the product's legal and public-data boundaries. The layout collapses to one column on narrow screens while maintaining source order, labels, keyboard focus and readable transaction status.
